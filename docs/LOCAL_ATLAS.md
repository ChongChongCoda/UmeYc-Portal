# 离线地图册（本地网页应用）

Portal 可以把一个静态网页应用（目前针对《女王魔域》2D/3D 离线地图册）作为本地只读站点打开，数据仍然放在 SD 卡或内置存储，不会复制进插件包。

## 准备地图册

1. 把地图册压缩包解压到 Deck：
   - SD 卡：`/run/media/deck/<卡名>/女王魔域地图册/`
   - 内置存储：`/home/deck/女王魔域地图册/`
2. 确认目标文件夹里有 `index.html`、`world.html`、`items.html` 以及 `connected/`、`regions/`、`layers/` 等目录。
3. 如果选择的是外层文件夹、且里面只有一个带 `index.html` 的子目录，插件会自动进入该子目录。

## 打开地图册

1. 游戏模式按「…」→ Decky → UmeYc-Portal → **本地文件与地图册**。
2. 在「离线地图册」中选择文件夹；校验通过后出现：
   - **2D 地图**：Canvas 世界地图、筛选、楼层、搜索。
   - **3D 地图**：WebGL 连通世界、实景/飞行模式。
   - **物品查询**：全物品与获取来源搜索。
3. 地图在 Portal 阅读器中打开；触屏可直接拖动、缩放、点击标记。
4. 需要搜索时，点网页标题栏右侧的 **放大镜**：在 Deck 原生输入框中输入关键词，插件会通过 CDP 把文字写入地图/物品页的搜索框并触发筛选。不要直接点地图页里的输入框调 Steam 键盘——内嵌 CEF 的候选框可能被窗口遮挡、选词也可能丢失。

## 技术实现

- `local_app.py` 提供独立的只读 loopback 服务，默认端口 `8137`（占用时自动换随机端口）。
- 每个地图册目录分配随机令牌；路径穿越、符号链接逃逸和外部 Host 都会被拒绝。
- CSP 允许同源脚本、样式和图片，但禁止 `connect-src` 等一切网络访问；地图册本身也不需要联网。
- 大文件返回 ETag，浏览器重复打开时走 304；不会把 691MB 数据复制到插件目录。
- 只允许选择 `DECKY_USER_HOME` 或 `/run/media` 下的目录。

## 性能与限制

- 3D 需要 WebGL。地图内画质建议先用「流畅」；如果掉帧明显，改用 2D 地图。
- 地图册数据由第三方社区制作，包含游戏素材，仅供个人使用；请遵守其 `COPYRIGHT.md`，不要随插件分发。
- 当前阶段只做了打开和触屏/键鼠操作；专用手柄映射（左摇杆平移、右摇杆旋转/缩放、A 点击、B 返回）在下一阶段实现。
- 地图册页面不会写入浏览历史，也不会在重启后尝试恢复带令牌的地址。

## 常见错误

| 提示 | 原因 | 处理 |
| --- | --- | --- |
| 这个文件夹里没有 index.html | 选到了压缩包外层或错误目录 | 进入含 `index.html` 的那层 |
| 地图册缺少可打开的页面 | 目录不完整 | 重新解压完整包 |
| 地图册文件夹不可用 | SD 卡未挂载 | 插回同一张卡或重新选择 |
| 3D 地图暂时无法显示 | WebGL 不可用或加载失败 | 使用 2D 地图，或检查地图内报错 |
