在 Steam Deck 游戏模式中边玩边看攻略：中文网页/图片浏览器，随「…」侧栏显示。

## 本版更新

- 修复 B 站切换下一集后空格快捷键发送失败，同时保持右摇杆滚动、R3 视频全屏和网页缩放可用。
- 切集自动同步当前标题与实际网址，新增历史并保留上一集；同步不会刷新正在播放的视频。
- 浏览历史增加到 20 条，重复访问移到最前；B 站按视频及分 P 去重，忽略分享和追踪参数。

## 已包含的功能

- 网页与本地攻略长图随侧栏显示，支持右摇杆滚动及会话内阅读位置记忆。
- 手机扫码发送网址或上传图片，保存位置可选；自动选择优先 SD 卡并显示实际目录。
- 本地文件默认使用上传目录，支持打开与确认删除；历史记录可单独删除。
- 所有操作面板使用左侧阅读区域，右侧插件侧栏保持展开。
- 可选侧栏展开继续、收起暂停，以及按下右摇杆切换视频全屏。

## 安装

1. 先安装 Decky Loader。
2. 下载本页附件 **UmeYc-Portal.zip**，请勿使用 GitHub 自动生成的 Source code 压缩包。
3. 在 Decky 设置中从 ZIP 安装插件，选择该文件并确认。

从旧名称 Portal 升级时，先卸载旧插件，再安装 UmeYc-Portal。
