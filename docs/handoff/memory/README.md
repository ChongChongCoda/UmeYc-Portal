# Claude 记忆快照

这里是从旧电脑 `~/.claude/projects/.../memory/` 复制出的、与本项目有关的记忆文件。

- `umeyc-portal-offline-fork.md`：项目地址、已实现功能、版本状态、实机坑（Decky 保留钩子、键盘、自动更新证书等）。
- `github-network-proxy.md`：旧电脑访问 GitHub 的代理/镜像经验，只对旧环境有效，新电脑按实际网络处理。

**不安装也可继续**：直接让 Claude 读这两个 Markdown 即可。

如果希望新电脑的 Claude 自动带上记忆，可把它们复制到：

- Windows：`C:\Users\<用户名>\.claude\projects\<项目路径编码>\memory\`
- Linux/macOS：`~/.claude/projects/<项目路径编码>/memory/`

并在同目录 `MEMORY.md` 增加对应的一行索引。项目路径编码由 Claude Code 生成，最稳妥的做法是新电脑上先打开本文件夹一次，再找到 `~/.claude/projects/` 下对应目录。
